# Procurement Vendor Management System

A full-stack **Procurement Vendor Management System** developed using **Java** for the backend and **JavaScript, HTML, and CSS** for the frontend. The application helps organizations manage vendors, procurement activities, and related records through a simple and efficient interface.

---

## 📌 Features

* Vendor Registration and Management
* Add, Update, Delete, and View Vendor Details
* Procurement Request Management
* Vendor Information Search
* User-Friendly Dashboard
* Secure Backend APIs
* Database Integration
* Responsive Frontend Interface

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Arun-05y/Procement-Vendor-Management-System.git
```

### 2. Navigate to the Project

```bash
cd Procement-Vendor-Management-System
```

### 3. Start the Backend

```bash
cd backend
mvn spring-boot:run
```

### 4. Start the Frontend

Open the **frontend** folder and launch the application using your preferred development server or browser.

---

## 🗄️ Database Configuration

Update the database configuration in the backend application properties.

Example:

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/procurement_db
spring.datasource.username=root
spring.datasource.password=your_password
```

Create the required database before running the application.
